# 작은 섬

폰 홈 화면 배경화면에서 주민들이 일하고, 배가 바다를 건너 항구를 오가는 방치형 게임입니다.

## 폰에서 설치하기

1. 최신 테스트 빌드 받기: [little-island.apk](../../releases/latest/download/little-island.apk)
2. 설치할 때 "출처를 알 수 없는 앱" 허용
3. 앱을 열고 **배경화면으로 설정**

코드를 main에 올릴 때마다 GitHub Actions가 새 APK를 만들어 릴리스에 올립니다. 같은 서명 키를 쓰므로 지우지 않고 덮어 설치할 수 있습니다.

## 지금 들어간 것 (1단계)

- 라이브 배경화면: 내 섬(1페이지), 항해 중인 바다(2페이지), 항구(3페이지)
- 실제 시간에 맞춘 낮, 노을, 밤과 불빛
- 나무를 베고 돌을 캐는 주민들
- 홈 화면 페이지 넘김을 지원하지 않는 폰에서는 섬만 보여줌

`app/debug.keystore`는 테스트 설치용 키입니다. 스토어 출시용 키는 따로 만듭니다.
