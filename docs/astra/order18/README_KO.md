# 리틀 아일랜드 — 18차 그림과 16차 선원 자료

이번 묶음은 마을 성장 건물 6개, 새 선원 카드 틀, 강화 반짝임 4장면을 담은 **18차 그림 자료**입니다. 함께 요청한 **16차 완료본의 Lv30·Lv50 선원 얼굴 2장과 Lv20·30·40·50 스킬 문구**도 포함했습니다. 16차 자료는 새로 생성하거나 수정하지 않고 완료본의 바이트를 그대로 옮겼습니다.

게임 코드는 수정하지 않았습니다. 파일 규격과 배치 정보는 `asset_layout.json`, 이번 검수 범위는 `QA_REPORT.json`, 기존 16차 파일의 원본 일치 기록은 `order16_inclusion.json`을 확인하세요.

`preview/order18_overview.png`는 한눈에 보는 비교 그림, `preview/upgrade_burst_preview.gif`는 강화 효과의 반복 미리보기입니다. 둘 다 앱용 원본 대신 사용하지 않습니다. GIF는 효과 400ms 뒤 600ms 쉬었다가 반복하며, 실제 게임에 연결하거나 실행한 결과는 아닙니다.

## 마을 건물 순서와 배치

번호는 왼쪽부터 **0부터 시작**합니다. 여섯 건물의 셀 크기는 모두 256×512이며, 원본 영역은 `x=번호×256`, `y=0`, `width=256`, `height=512`입니다.

| 번호 | 배 단계 | 건물 | 원본 x 범위 |
|---|---|---|---|
| 0 | 2단계 | 청록·상아 줄무늬 섬 깃발 | 0 이상 256 미만 |
| 1 | 4단계 | 흰 돌탑과 붉은 지붕의 풍차 | 256 이상 512 미만 |
| 2 | 5단계 | 두 기둥 사이 종이 등불 5개 | 512 이상 768 미만 |
| 3 | 7단계 | 푸른 뾰족 지붕과 금색 종의 종탑 | 768 이상 1024 미만 |
| 4 | 8단계 | 높이가 다른 해적 깃발 트로피 3개 | 1024 이상 1280 미만 |
| 5 | 10단계 | 망원경을 든 선장 황금 동상 | 1280 이상 1536 미만 |

마을 건물은 셀 아래쪽을 바닥 기준으로 삼습니다. 같은 256×512 셀인 기존 `buildings.png`와 같은 배율·바닥 기준으로 놓으면 작은 집보다 높이 솟는 구성이 됩니다. 중심 위치를 맞추려고 건물마다 제각각 잘라 내거나 높이를 같은 값으로 늘리지 마세요. 건물의 정확한 경계와 정렬 검수 내용은 `asset_layout.json`과 `QA_REPORT.json`에 따릅니다.

## 새 선원 카드와 강화 반짝임

`new_crew_card.png`는 **빈 카드 틀**입니다. 위쪽의 밝은 하늘색 창에 기존 선원 얼굴을 놓고, 아래쪽 짙은 갈색 영역에 이름과 한마디를 앱에서 표시합니다. 빈 리본에도 글자는 앱에서 표시합니다. 카드 창·문구 영역의 좌표는 `asset_layout.json`을 기준으로 연결하세요.

512×640 원본 기준 얼굴 창은 x66~446, y135~362이고, 글 영역은 x66~447, y382~544입니다(끝 좌표 미포함). 얼굴과 글은 테두리에 닿지 않도록 `portrait_safe_rect`, `text_safe_rect` 안에 배치합니다.

`upgrade_burst.png`는 왼쪽부터 1→2→3→4 순서로 사용하는 4장면입니다. 원본 영역은 `x=장면번호×256`, `y=0`, `width=256`, `height=256`이며 장면번호는 0부터 시작합니다. 작은 터짐→큰 터짐→바깥으로 퍼짐→잔여 반짝임의 흐름입니다. 강화 수치는 비워 둔 중앙 위에 앱에서 표시합니다. 원본 크기가 같은 네 셀을 같은 중심에 놓고, 그림의 실제 경계만 따라 움직이지 않도록 합니다. 재생 시간과 화면 좌표는 현재 연출에 맞춰 연결하며, 이 묶음이 앱 코드를 변경하지는 않습니다.

네 장면에서 공통으로 완전히 비어 있는 중심 영역은 각 셀의 x98~158, y110~146(60×36픽셀)입니다. 효과와 숫자를 같은 중심에 놓되, 숫자가 더 크면 효과 전체의 표시 배율을 조정해 겹침을 확인하세요. 제안 재생 시간은 70→90→100→140ms, 총 400ms 후 숨김입니다.

## 함께 넣은 16차 자료

얼굴 두 시트의 인물 순서는 기존과 같습니다. 왼쪽 위부터 행 우선으로 여울, 문기, 소리, 누리, 바다, 건우, 도리, 하늘, 빛여, 들, 새이, 온유입니다. 원본 영역은 `x=(번호%4)×128`, `y=floor(번호/4)×128`, 크기는 128×128입니다. 이전 256픽셀 셀 좌표를 이 시트에 그대로 쓰지 마세요.

Lv50 이상은 50 시트, Lv30~49는 30 시트를 연결하고, 그보다 낮은 레벨은 현재 얼굴 선택을 유지합니다. 기존에 이 두 그림을 이미 적용했다면 다시 바꿀 필요가 없습니다.

스킬 JSON은 16차에서 **`name`, `short`만 다듬은 완료본**입니다. `crew`, `level`, `id`, `effect`, `value`, `icon_index`와 배열 순서·원본 메타데이터는 보존되어 있습니다. 그 이후 저장소의 스킬 수치나 항목이 바뀌었다면 같은 `id`를 대조해 표시 필드 두 개만 옮기고 현재 수치·획득 상태를 이전 상태로 덮어쓰지 않습니다. 최상위 `note`의 “임시 이름”은 보존한 원본 문구이며 이번 파일이 미완성이라는 뜻이 아닙니다.

16차의 기존 안내·검수 문서 5개는 `docs/order16/`에 원본 그대로 들어 있습니다. 그 문서 안의 `art/`, `data/` 경로는 이 ZIP의 최상위 폴더를 가리킵니다.

## 참고 자료와 확인 범위

건물의 크기감과 바닥선은 이전에 제공된 프로젝트의 `buildings.png`와 `ART_GUIDE.md`를 참고했습니다. 선원 화풍은 기존 초상 자료를 참고할 수 있도록 회수했습니다. **build-79의 `village_growth.png`, `new_crew.png` 스크린샷은 확보하지 못해 최신 게임 화면과 직접 대조하지 못했습니다.**

실제 앱 빌드·설치·게임 실행과 연출 연결은 수행하지 않았습니다. 적용 후에는 건물의 바닥 정렬, 선원 얼굴과 카드 창의 겹침, 이름·대사의 가독성, 강화 숫자와 반짝임의 겹침을 실제 화면에서 확인하세요. 그림을 연결하는 작업으로 선원 성장·획득·강화·보상을 다시 실행하지 않도록 현재 저장 상태를 유지합니다.
