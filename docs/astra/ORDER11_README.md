## 선원 사건과 대사

35의 단독 사건은 각 선원 Lv12·Lv15에 하나씩 열립니다. 짝 사건은20의 기존 시너지6쌍을 먼저 쓰고 다른6쌍을 더했습니다. `crew`가 주인공이며 그 선원의 레벨 조건과 `with` 선원의 승선을 출항 스냅샷으로 검사합니다. 파트너에게 별도 레벨 조건을 새로 만들지 않았습니다. 짝 사건의 카드에는 두 이름이 모두 나오고, 감정·경험치 주체는 주인공 한 명입니다.

33과35를 합친 한 사건 목록에서 항해당25%를 한 번만 검사합니다. 파일마다 따로 검사하거나 짝 사건을 추가로 뽑지 않습니다. 선원 수가 늘어도 한 항해 최대 사건 하나입니다. 35에서 효과 없는 사건은12개입니다. 기존 감정 연출 시점·귀항 지급·Lv15 경험치 상한·오프라인 최대8시간·중복 지급 방지는 유지합니다. 사건은 일지에 쌓지 않습니다.

40은 요청대로 `crew` 배열과 `worker_id / deck_lines / fight_lines`만 담았습니다. 실제로 승선한 선원이 Lv11 이상일 때21의 같은 상황 대사에40의 대사를 추가해 기존 방식으로 섞습니다. Lv10 이하는 기존21만 사용합니다. 갑판과 전투 대사 목록을 서로 섞지 않으며 등장 주기를 늘리거나 음성 파일을 추가하지 않습니다.

## 오늘의 주문

31의30개에36의30개를 ID로 합쳐60개에서 고릅니다. 이미 발급된 오늘 주문·진행·보상·주간 기준일은 보존합니다. 신규 목록은 다음 미발급 날짜부터 사용합니다.

## 부적과 꾸미기

37은28의 부적 목록에만 추가합니다. 확률·천장·중복·역할 일치·효과 합산 상한은28을 그대로 참조하며 새 규칙으로 덮어쓰지 않습니다. 목재값·보물·좋은 사건·패배 시 짐 손실 감소 효과를 등급별로 하나씩 넣었고, 잘 맞는 선원은12명에게 하나씩 배정했습니다. 기존에 없는 영웅 목재값·손실 감소의 두 배열은 같은 등급의 크기를 참고한 신규 제안이며 근거를 validation_reference에 구분했습니다.

꾸미기16개는 새 보스 전리품4·오래 한 기록4·금화 구매4·기타 조건4로 나뉩니다. 기록은 항해100회·300회, 보물20회, 승진 선원Lv15입니다. 구매 장식은 배5 조건에서 각각 금화10,000·16,000·22,000·30,000이며 자동 구매하지 않습니다. 기존 장식과 마찬가지로 전투나 생산 효과는 없습니다.

허용된 조건5종만 사용하고, `counter_at_least`에는 `voyages / treasures`만 사용했습니다. 도감 이정표는26의 실제ID를 참조합니다. 기존 기록이 조건을 이미 충족한 경우 기존 획득 규약으로 한 번 지급하고, 이미 가진 물건을 다시 지급하거나 구매비를 다시 차감하지 않습니다.
