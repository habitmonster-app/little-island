# 리틀 아일랜드 — 아홉 번째 전달 자료

오늘의 항구 주문 30개, 선원 12명의 세 번째 특별 항해와 마지막 이야기, 그림 시트 4장을 담았습니다. 앱 소스는 변경하지 않았습니다. build-33에 추가할 데이터·그림 패키지이며 앱 실행 검증은 하지 않았습니다.

## 클로드 적용 순서

1. 기존 저장을 보존하고 31을 새 주문 데이터로 추가합니다. 화면에는 짧은 title·short와 앱이 만든 진행 수치만 표시합니다. JSON의 긴 규칙 문단은 구현 설명이므로 앱 설명창에 출력하지 않습니다.
2. 23의 임무 24개에 32의 신규 12개를 ID로 합칩니다. 총 36개이며 기존 임무 조건·본문·완료 이력을 덮어쓰지 않습니다.
3. 기존 임무와 새 임무 모두 30의 Lv15 경험치 함수를 사용합니다. 23의 옛 Lv10 상한 문구를 새 경험치 처리에 적용하지 않습니다.
4. 선원 Lv11 이상일 때 새 갑판 시트를 사용합니다. 파일명은 요청대로 `_15`지만 사용 시작은 Lv11입니다. 그 아래 레벨은 기존 그림을 유지합니다.
5. 31의 counter와 원래 기능의 확정 이벤트를 연결하고, 날짜 경계·중복 정산·최종 강화·전부 수집한 저장에서 확인합니다. 이 패키지는 이벤트 연결 코드를 포함하지 않습니다.

## 오늘의 주문

- 기본 슬롯은 쉬움·보통·어려움 하나씩입니다. 적격 주문 안에서 무작위 선택하며 후보가 없을 때는 낮은 난도로만 대체합니다. 쪽지는 각각 1·2·3장, 일일 합계 최대 6장입니다. 금화는 합계 최대 60입니다.
- 최종 부품·모든 기념품 수집·완료된 모든 임무처럼 실행할 수 없는 주문을 제외합니다. 발급 뒤 남은 훈련 시도 등을 소진해 영구적으로 불가능해진 미완료 슬롯은 쉬운 귀항 주문으로 자동 대체합니다. 교체한 슬롯도 완료와 보상은 한 번뿐입니다.
- 보스 주문은 배2 이상, 어려움 1개, 목표1입니다. 같은 주간 묶음에서 최대 한 번만 등장합니다. 확률 콘텐츠의 당일 완료를 보장하지 않습니다.
- 첫 발급일을 기준으로 7일씩 묶고 15개 완료 시 주간 상자 1회, 쪽지10장·금화500을 추가 지급합니다. 주간 상자는 일일6장 한도와 별개입니다. 완료 즉시 지급하고 상자 연출은 재지급하지 않습니다.
- 주문은 날짜별로 저장합니다. 재실행으로 다시 뽑지 않으며, 오프라인은 기존 최대8시간 안의 실제 이벤트 시각과 이미 발급된 게시판만 인정합니다. 접속하지 않은 날의 주문을 만들어 주지 않습니다.

## 세 번째 특별 항해

- 선원 Lv12·배4 이상·본인 승선·본인의 임무2 완료가 필요합니다. 먼 항구 다섯 곳을 사용하며 추가 부품 조건을 새로 만들지 않았습니다.
- 신규 본문은 각각 439~467자입니다. 첫 섬 생활과 앞선 임무를 돌아보고 자신의 역할을 다른 사람과 나누는 이야기로 마무리합니다.
- 최초 성공 추가 보상은 금화2,000~2,800과 주인공 경험치60입니다. 일반 항해 판매·전투 보상은 별도로 기존대로 정산합니다. `reward.cosmetic_id`는 요청대로 아예 없습니다. 키 누락은 꾸미기 지급 없음으로 처리합니다.
- 금화 보상은 진입 가능한 최소 배4·선체15의 만재 목재/돌 판매액 기준 약2.25~2.48항해입니다. 새이는 임무2의 선체18 조건까지 포함해 검산했습니다. 특산물·선원·시장·전투 보너스는 비교에서 제외했으며, 모든 배와 편성의 현재 순이익을 보장하는 수치는 아닙니다.
- 기존 예약·출항 스냅샷·첫 성공 1회 지급 규약을 유지합니다. 실패하면 다시 선택할 수 있으며, 새 임무를 자동으로 연속 실행하지 않습니다.

갑판 열 순서는 밧줄 당기기·키 돌리기·대포 장전·한 팔 환호입니다. 기존 셀 좌표와 발 위치를 유지하도록 0~1px 수직 정렬했으며 확대·축소하지 않았습니다. 키 받침의 맨 아래를 발 위치로 오인하지 않도록 기존 신발 영역을 대조했습니다. 맨 위부터 왼쪽→오른쪽으로 자르고 최근접 보간을 사용하세요.

갑판과 아이콘은 불투명 PNG의 마젠타를 기존 처리대로 제거합니다. 이야기 그림은 마젠타 제거 대상이 아닙니다. 실제 얼굴·머리·모자·동작은 시각적으로 대조했으며 픽셀 단위로 동일한 복제본을 뜻하지 않습니다.

이야기 그림의 인물 순서는 여울·문기·소리·누리·바다·건우·도리·하늘·빛여·들·새이·온유입니다. 각자의 소품은 밧줄·대포 솔·장부·짐표·돛 천·망치·키 손잡이·편지·망원경·국자·금화 주머니·구명 튜브입니다.

삽화는 요청한 배5의 큰 갑판을 참조한 근접 장면으로, 전체 선체나 돛대 세 개를 한 화면에 보여 주는 배 도감 그림은 아닙니다. 배4에서도 마지막 일지 삽화로 표시하며 배5 소유 조건이나 승급 보상을 추가하지 않습니다.

## 확인 범위

주문 개수·허용 counter·문구 길이·ID 참조·보상 상한·12편의 조건과 서사 연결·이미지 크기와 순서·발 위치·압축 무결성을 확인했습니다. 앱에 연결한 뒤의 실제 화면, 이벤트 발생, 저장 복원, 오프라인 결과는 클로드 통합 단계에서 확인해야 합니다. 18 경제표·15 출시 문서·소리·영어판·앱 코드는 수정하지 않았습니다.
