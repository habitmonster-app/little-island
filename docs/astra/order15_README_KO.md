배 7~10단계의 이름·설명과 새 그림, 망루·선실 아이콘을 연결하는 자료입니다. **데이터 1개, PNG 5장, 안내 문서 5개로 총 11개 파일**입니다. 앱 코드는 수정하지 않았으며 실제 게임 실행·통합 빌드 테스트는 하지 않았습니다.

이번 기준은 주문서에서 알려 준 **배 10단계·부품 여섯 종 Lv50·별 강화·변경된 승률과 약탈 규칙이 있는 현재 앱**입니다. 이전 주문의 수치나 상한으로 되돌리지 않습니다.

## 적용 순서

1. 현재 앱과 저장을 백업합니다. 배 단계와 여섯 부품·별 강화가 들어간 최신 확장 상태를 기준으로 적용합니다.
2. 54의 level과 같은 기존 배 항목을 찾고 **name, look, home_news, desc 네 필드만** 반영합니다. 기존 배 항목 전체나 ships 배열 전체를 54로 교체하지 않습니다.
3. 배 7~10단계에 각각 해당 시트의 0행을 연결합니다. 외형 칸은 **막 산 모습 → 선체 보강 → 돛 정비 → 대포·깃발 정비** 순서입니다.
4. 망루에는 새 아이콘 시트의 0번, 선실에는 1번을 연결합니다. 실제 부품 ID는 현재 앱의 값을 그대로 사용합니다.
5. 기존 저장을 불러와 아래 확인 항목을 실제 화면에서 점검합니다.

현재 배 10단계 상한과 단계별 짐·속도·승률·비용·해금, 여섯 부품 Lv50, 별 강화 조건·비용·효과·저장된 별 수를 유지합니다. 망루의 발견·회피와 선실의 선원 능력치 효과도 기존 계산을 그대로 씁니다.

낮아진 승률과 패배 시 짐·금화 약탈을 유지합니다. 따뜻한 배 설명은 전투 규칙을 바꾸지 않습니다. **47번의 배 6단계 상한·부품 Lv30·네 부품 구조·과거 승률·효과 상한을 이번에 다시 병합하지 마세요.**

선원 성장과 승선 배치, 꾸미기 장착, 도감·일지, 진행 중 항해도 보존합니다. 파일 재적용이나 이름 변경만으로 승급·보상·귀항 소식을 다시 실행하지 않습니다. 새 배 항목이 없는 구버전에는 수치가 없는 54를 배 생성 자료로 사용하지 않습니다.

## 그림 배치 기준

모든 셀 번호는 0부터 시작하며 왼쪽에서 오른쪽 순서입니다. 마젠타를 투명 처리하고 최근접 보간으로 표시합니다. 선원과 장식을 붙이는 기준은 기존 ship_stage6.png를 따릅니다.

원본 기준 수면 앵커는 **y246**, 마지막 선체 픽셀은 **y247**입니다. 갑판 발선 **y184는 육안 근사 기준**입니다. 현재 앱의 단계별 표시 크기와 부착 좌표에서 실제로 맞는지 확인해야 합니다. 과거 6단계 표시 크기 60×46을 새 모든 단계에 강제로 적용하지 않습니다.

주문서의 너비 비율은 대략값입니다. 실제 6단계 원본은 최대 240픽셀로 이미 256픽셀 칸의 약94%를 차지합니다. 새 배를 더 작게 만들지 않도록 7~10단계 목표 폭을 **242·245·248·251픽셀**로 점차 늘렸습니다. 최종 폭과 정렬의 실측·처리 범위는 매니페스트를 우선하세요.

새 외형 선택은 현재 앱의 여섯 부품·별 강화 흐름에 연결합니다. 이전 47의 네 부품 수나 Lv28 기준 공식을 복사하지 않습니다. 그림에 보이는 돛·대포 수를 새 성능 수치로 환산하지 않습니다. 이름판은 글자 없는 표식입니다.

part_icons_2.png의 0·1번은 새 시트 안의 지역 번호입니다. 기존 part_icons.png의 첫 두 칸과 혼동하거나 덮어쓰지 않습니다.
