## 클로드 적용 메모

33은 새 데이터로 추가합니다. 실제 화면에는 짧은 card_title·card_line과 앱이 붙이는 보상만 표시합니다. 긴 확률·정산 설명은 구현 규약이므로 화면에 출력하지 않습니다.

선원 사건은 항해당25%를 한 번만 검사하고 최대 하나를 선택합니다. 승선한 적격 선원을 균등 선택한 뒤 해당 선원의 열린 사건 중 하나를 고릅니다. Lv10 선원은 자신의 이전 레벨 사건도 계속 만날 수 있습니다. 아무 효과 없는 사건은12개이며 따로 실패나 손해를 주지 않습니다.

항해 시간65% 지점에서 해당 선원 머리 위에 감정을 잠깐 표시하고, 실제 보상은 귀항할 때 한 번만 지급합니다. 경험치는 그 선원 한 명에게만 주고30의 Lv15 상한을 적용합니다. 사건은 일지에 쌓지 않습니다. 오프라인 감정 연출을 몰아서 재생하지 않으며, 중복 지급 방지 기록은 유지합니다. 07 기존 항해 사건·전투·본편 고정 사건과 별개의 작은 일상 슬롯입니다.

34의 training_puzzle.puzzles를28의 기존9개에 ID로 합쳐 총39개로 사용합니다. 신규ID는 training_cargo_10부터39까지입니다. 항목의5개 키는 기존과 같고, 판은 initial 배열 길이6이면2행,9이면3행입니다. 항상3열이며 정답은 각 행 wood·stone·grain 순서입니다.

훈련은 기존처럼 하루3회·60초·최대4교환입니다. 인접하지 않은 칸도 교환할 수 있고, 같은 종류끼리는 횟수를 쓰지 않습니다. 최단 성공3쪽지·한 번 더 교환하면2쪽지·그 외 성공1쪽지 규칙과 하루최대9쪽지를 유지합니다. 네 번째 교환으로도 성공할 수 있습니다. 빈칸 밀기 퍼즐이 아니므로 기존 training_crates.png의 네 번째 빈 갑판 그림은 사용하지 않습니다.

업데이트 당일 이미 정한 문제와 진행 중인 도전은 보존합니다. 새39개 문제 풀은 아직 발급하지 않은 다음 날짜부터 씁니다. 새3×3판을 위해 도전권이나 보상 저장소를 따로 만들지 않습니다. 새 문제의 성공도31의 training_clear에 한 번만 전달하고 cargo_pack에는 더하지 않습니다.

## 검증 범위

사건36개의 선원·레벨·문구·감정·보상 범위와 기존 규칙 연결을 확인했습니다. 퍼즐은6칸의90상태와9칸의1,680상태를 각각 전체 탐색해 신규30개의 정답 경로와 최소 교환 횟수가 정확한지 독립 검증했습니다. 신규 문제는 기존9개와 겹치지 않으며 모두4회 이내에 풀립니다.
