## 통합할 때 지킬 점

- **도감:** 기존 kind 0~7에 새 kind 8~13을 더해 총 열네 종이 됩니다. 기존 발견·보상·칭호는 보존합니다. 48의 네 종·여덟 종 보상과 `물결의친구` 조건은 **원래 여덟 종만** 세며 새 여섯 종을 섞지 않습니다. 새 전체 완성 보상은 추가하지 않습니다.
- **그림 번호:** 52의 `icon_index` 0~5는 `seabed_book.png` 안의 번호입니다. 기존 도감 그림과 **시트 이름까지 함께** 구분합니다. kind 번호를 그림 칸 번호로 쓰지 않습니다. 노란 장식 물고기·거품·진주 조개는 도감 종이 아닙니다.
- **발견:** 화면에 실제로 보이는 유효 동물을 직접 누를 때 종별 한 번만 기록·지급합니다. 무리와 애니메이션 프레임 수는 종 수가 아닙니다. 발견 기록과 보상 지급 표식을 함께 저장하고 재접속·연속 탭으로 다시 지급하지 않습니다.
- **정원:** 기존 완료 항해 횟수를 사용합니다. 산호/해초 수는 `(2,2) → (3,2) → (3,3) → (4,4) → (5,5) → (6,6)`입니다. 여섯 단계에서 각각 두 개부터 여섯 개까지 두 종류 모두 매번 늘리는 것은 불가능하므로 초반에 번갈아 늘렸습니다. 각 단계의 수는 최종 배치 수이며 이전 수와 합산하지 않습니다. 성장할 때 기존 자리는 보존하고 새 자리만 켭니다.
- **진주:** `chance_per_hour: 0.5`는 입력 가능한 홈 장면의 **누적 유효 활동시간 한 시간당 추첨 한 번**의 확률입니다. 프레임마다 추첨하거나 재접속 때 다시 뽑지 않습니다. 오프라인 시간은 포함하지 않습니다. 성공 시 진주를 보여 주고 직접 눌렀을 때 쪽지·금화를 한 번 지급합니다. 닫힘·열림 애니메이션 자체는 보상이 아닙니다.
- **진주 표시 시간:** 입력 가능한 전경시간 **60초 동안 수령 가능**하게 하는 통합 기본안을 제안합니다. 화면을 벗어나면 남은 시간을 저장해 재개하며 처음부터 다시 채우지 않습니다. 이는 새 JSON 필드나 이미 구현된 기능이 아니므로 실제 앱에서 표시와 조작감을 확인하세요.
- **선원 대사:** 우리 섬에 실제 정박했을 때 현재 승선한 선원만 말합니다. 기존 말풍선 차례를 공유하고 날씨·짝 대화와 겹쳐 재생하지 않습니다. 대사 때문에 도감 발견·진주 열림·보상·정원 성장이 발생하지 않습니다.

## 그림을 표시하는 기준

장면은 200×467, 수면은 y252입니다. 그림을 수면 아래에 클립하고 낮 기준 원화를 사용합니다. 밤에는 기존 어두운 덮개를 유지합니다. 처음 다섯 그림은 **마젠타 `#FF00FF`**, 빛줄기는 **검정 `#000000`**을 배경 키로 처리합니다. 빛줄기에 마젠타 키 처리를 적용하지 않습니다.

밑바닥 띠는 좌우 반사 조립으로 양끝 연결을 정규화한 반복 그림입니다. 띠를 옆으로 흘릴 때 이음새를 실제 표시 크기에서 확인하세요. 식물과 바닥 친구는 매니페스트의 공통 접지 기준을 사용하고, 물고기는 원화대로 왼쪽으로 이동합니다. 거품·빛줄기는 천천히 반복하되 밤의 밝기 덮개를 무시하지 않게 합니다.

빛줄기는 한국어 주문의 크기대로 **가로 네 칸**입니다. 도감 마지막 두 칸은 빈 마젠타이며 생물로 등록하지 않습니다. 조개는 네 칸을 계속 순환하는 장식 루프로 쓰지 않고 `닫힘 → 열림 → 진주 표시 유지 → 닫힘` 상태에 맞춰 표시합니다. 자세한 셀 순서·실제 처리·좌표는 `ART14_MANIFEST.json`을 따릅니다.
