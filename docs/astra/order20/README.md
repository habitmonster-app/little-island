# 리틀 아일랜드 · 20차 배 장식

오른쪽을 향하는 배에 붙이는 장식 48개입니다. 게임 코드는 수정하지 않았습니다.

## 파일과 크기

모든 PNG는 **1024×768**, **4열×3행**, 한 칸 **256×256**입니다. 칸 순서는 왼쪽 위부터 오른쪽으로, 다음 행으로 진행합니다. 각 파일의 1~12번은 `cell_mapping.json`의 `display_number`와 같으며, 코드용 `index_0based`는 0~11입니다.

| 파일 | 내용 | 장식 크기 | 셀 안 부착점 (x,y) |
|---|---|---|---|
| `art/deco_flags.png` | 깃발 천 12개 | 가로205px | (0,128), 천 왼쪽 가운데 |
| `art/deco_figureheads.png` | 뱃머리 장식 12개 | 가로·세로 최대179px | (0,256), 왼쪽 아래 |
| `art/deco_sails.png` | 평면 돛 무늬 12개 | 가로·세로 최대154px | (128,128), 가운데 |
| `art/deco_deck.png` | 갑판 물건 12개 | 가로·세로 최대154px | (128,256), 아래쪽 가운데 |

`cell_mapping.json`에 48개 한국어 이름, 고정 순번, 셀 위치, 부착점이 들어 있습니다. 이번 파일은 종류별12칸이므로 과거 장식 시트의4×4 구조로 읽으면 안 됩니다.

## 배에 붙이는 방법

부착점은 **256×256 셀의 논리적 가장자리 좌표**입니다. `256`은 마지막 픽셀 인덱스가 아니라 바깥 가장자리이고, 마지막 픽셀 인덱스는 `255`입니다. 뱃머리는 바운딩 박스 왼쪽0·아래256에, 갑판 물건은 아래256·가운데128에 맞춥니다.

1. JSON의 `rect_px`에 따라 전체256×256 셀을 잘라 사용합니다. 자동으로 빈 여백을 잘라내면 부착점이 달라집니다.
2. 배 위 목표 부착점을 `(attachX,attachY)`, 확대율을 `scale`로 정합니다.
3. `draw_x = attachX - anchorX * scale`, `draw_y = attachY - anchorY * scale` 위치에 셀을 `256 * scale` 크기로 그립니다.

깃발의 `(0,128)`은 **천의 왼쪽 부착점**입니다. 아래로 늘어진 술 때문에 전체 그림 바운딩 박스의 세로 중심과 천 부착점이 다를 수 있습니다. 바운딩 박스 전체의 중심으로 다시 정렬하지 마세요.

## 배경과 축소

PNG 배경은 불투명한 **마젠타 RGB(255,0,255), #FF00FF**입니다. 게임에서 이 색과 **정확히 일치하는 픽셀만** 투명 처리한 뒤 그리세요. 비슷한 색까지 범위로 제거하지 마세요. 작은 화면용 축소·확대에는 **최근접 이웃(Nearest Neighbor)** 방식을 사용해 경계를 유지합니다.

## 확인 범위

현재 `build-88/refit_decos.png` 화면은 확보하지 못해 직접 확인하지 않았습니다. 배 형태는 과거13차 `ship_stage6.png`(1024×256)를 참고했으며, 요청에 적힌 현재512×128 원본은 찾지 못했습니다. 따라서 최신 게임에서의 부착 위치와 가독성은 적용 후 확인이 필요합니다.
