## 적용 순서

1. 기존 자료와 저장을 백업하고 매니페스트의 파일·해시를 확인합니다. 섬 덮개는 통합 안내에 기록한 원본 `island_2.png`·`island_3.png` 해시와 비교합니다.
2. 47을 기존 배·경제·부품·승선 슬롯 자료에 ID/레벨 기준으로 추가 병합합니다. 기존 파일 전체를 47로 교체하지 않습니다.
3. 일곱 그림의 셀과 키 색상, 배 앵커, 섬 단계별 덮개를 연결합니다.
4. 48 도감·칭호 → 49 주간 효과 → 50 거래 횟수·일지 → 51 날씨 한마디를 연결합니다. 저장과 보상 표식은 UI 표시 전에 함께 확정합니다.
5. 기존 저장을 불러와 아래 항목을 실제 앱에서 확인합니다.

## 데이터 통합의 핵심

- **배:** 배 5단계와 네 부품 모두 Lv25가 필요합니다. 키 Lv25도 필수입니다. 키 효과는 이미 상한에 도달했으므로 진입 정비가 효과를 더 올리지는 않습니다. 배 6단계 이후 키 Lv26~30은 선택 정비이며, 선체·돛·대포만 Lv28이면 마지막 외형에 도달합니다.
- **창고·선원:** 창고 4단계는 기존 데이터에 이미 있습니다. 자원별 용량 1,800으로 승급 비용 목재 1,080·돌 900을 담을 수 있습니다. 선원은 최대 Lv15와 승선 여섯 자리를 유지합니다. 기존 효과 상한·배치·꾸미기·진행 중 항해도 보존합니다.
- **도감:** 현재 바다의 동물을 직접 누른 때만 발견합니다. 동물 ID와 문턱별 지급 표식으로 한 번만 정산합니다. `물결의친구`는 별도 안정 ID의 보기용 칭호로 등록하고 자동 장착하지 않습니다. 기존 칭호 그림의 없는 칸 번호를 만들지 않습니다.
- **주간:** 고정 월요일 `2026-01-05`와 달력 날짜 차로 열두 소식을 계속 순환합니다. ISO 주차의 나머지를 사용하지 않습니다. 날씨는 조건을 먼저 거른 뒤 가중치를 조정합니다. 항해는 출항, 의뢰 금화는 수락, 타이머는 예약 시점의 값을 유지합니다. 보너스와 추첨은 한 번만 적용합니다.
- **손님:** 손님별 성공 거래만 누적하고 이야기 ID별로 한 번 해금·지급합니다. 마지막 이야기 쪽지 두 장은 46의 거래 쪽지 한 장 상한과 별개인 일회성 보상입니다. 마지막 작은 선물 여덟 가지는 서사용이며 새 소장품·생산 효과를 추가하지 않습니다.
- **대사:** 실제 승선한 선원의 현재 항해 날씨로 51의 한마디를 선택해 기존 42 공통 한마디를 대체합니다. 두 말을 함께 재생하지 않습니다. 새 레벨 조건·보상·별도 말풍선 타이머는 없습니다.

## 그림을 겹치는 기준

셀 번호는 왼쪽에서 오른쪽, 위에서 아래로 세며 0부터 시작합니다. `visitor_story_art.png`는 배경을 채운 장면입니다. **나머지 여섯 그림은 순수 마젠타 `#FF00FF`를 투명 처리**하고 최근접 보간으로 표시합니다.

배 6단계는 별도 시트의 0행을 사용합니다. 기존 5단계의 128픽셀 칸 수면 앵커 y123을 새 256픽셀 칸의 **y246**으로 환산합니다. 기존 표시 크기 **60×46**과 선원·장식 부착 좌표를 유지합니다. 원본 해상도가 두 배라고 화면 배 크기를 두 배로 하지 않습니다. 갑판 발 위치 **y184는 육안 근사 기준**이므로 실제 앱의 기존 승선 좌표와 함께 확인하세요.

계절 덮개는 봄·여름·가을·겨울 순서입니다. 해당 행의 전체 1536×1024 셀을 원본 섬과 같은 원점에 **1:1로** 겹칩니다. 여백을 잘라 가운데 맞추지 않습니다. 앱에서 섬을 자르거나 확대했다면 덮개에도 같은 변환을 적용합니다. 2·3단계에 각각 새 시트를 쓰고 기존 4단계 시트와 45의 계절 장식·축제 규칙은 유지합니다. 원본 위 위치 정렬을 확인했지만, 생성한 계절 잎의 내부 픽셀이 원본 나무를 그대로 재색칠한 것은 아닙니다.

## 통합 후 필수 확인

- 기존 저장의 배·부품·선원 Lv15·여섯 자리·꾸미기·일지를 유지하고, 승급·거래·발견을 중복 클릭하거나 앱을 다시 열어도 비용과 보상이 한 번만 반영되는지 확인합니다.
- 배 외형 네 칸의 수면·선원 발·장식 위치와 섬 두 단계의 사계절 정렬, 마젠타 잔여를 실제 표시 크기로 확인합니다.
- 일요일→월요일과 연말→연초에 주간 순환이 이어지고, 진행 중 항해·수락한 의뢰·예약 타이머의 결과가 바뀌지 않는지 확인합니다.
- 도감 문턱·완성 칭호 선택, 손님별 거래 1·3·6의 일지와 별도 보상, 승선 선원의 날씨 대사 대체를 확인합니다.

새 데이터는 독립 정적 검사 844개와 수동 검토 32개를 통과했습니다. 이야기 24편과 대사 120줄을 모두 읽었습니다. 이는 **자료 검수 결과**이며 실제 build-41 통합 성공이나 장기 플레이 밸런스 검증을 뜻하지 않습니다. 새 배 수치와 저장·정산 절차는 이번 통합 제안이며, 측정된 그림 정보와 최종 검수 범위는 매니페스트 및 QA 보고서에 구분해 기록합니다.

18 수치 재조정, 15 출시 서류, 소리, 영어판, 신규 항구·해적은 이번 범위에 포함하지 않습니다.
