# 리틀 아일랜드 — 19차 출렁이는 수면

낮·저녁·밤 수면 띠 3장입니다. 물결의 모양, 거품 위치와 장면 순서는 세 그림이 같고 색만 다릅니다. 이번 묶음에는 19차 수면 자료만 들어 있으며 16~18차 자료는 다시 넣지 않았습니다. 게임 코드는 수정하지 않았습니다.

## 원본 파일

| 파일 | 시간대 | 물 띠 색 | 맨 아래 색 |
|---|---|---|---|
| `art/sea_surface.png` | 낮 | 청록 `#02C2CF` | 파랑 `#0174C5` |
| `art/sea_surface_dusk.png` | 저녁 | 분홍빛 보라 `#CA86BC` | 남보라 `#2B326B` |
| `art/sea_surface_night.png` | 밤 | 짙은 청록 `#146471` | 짙은 남색 `#07182E` |

세 파일 모두 **1024×512 PNG, 1열×4행**입니다. 한 장면은 **1024×128**이며, 위에서 아래로 1→2→3→4→1 순서로 재생합니다. 아래 좌표의 끝값은 포함하지 않습니다.

| 장면 번호(0부터) | 잘라 쓸 영역 `[왼쪽, 위, 오른쪽, 아래]` | 최초 장면에서 왼쪽으로 이동한 거리 |
|---|---|---|
| 0 | `[0, 0, 1024, 128]` | 0px |
| 1 | `[0, 128, 1024, 256]` | 64px |
| 2 | `[0, 256, 1024, 384]` | 128px |
| 3 | `[0, 384, 1024, 512]` | 192px |

한 장면 안에는 물결이 4개 있고, 가로 반복 주기는 256px입니다. 장면마다 같은 무늬가 왼쪽으로 64px씩 이동합니다. 마지막 장면 다음의 이동량 256px는 반복 주기 하나와 같으므로 첫 장면으로 돌아갑니다. 가로로는 같은 장면을 계속 이어 붙여 사용합니다.

## 기존 수면 위에 놓는 기준

**물결의 가장 낮은 골인 셀 내부 y76을 기존 직선 수면에 맞춥니다. 셀 중앙 y64에 맞추지 마세요.** 중앙을 기존 수면에 맞추면 골 위의 투명 영역 사이로 기존 직선 경계가 보일 수 있습니다.

물결 경계는 한 장면 안에서 y52~76에 있으며, 높이 차이는 24px(셀 높이의 18.75%)입니다. 배치 기준은 다음과 같습니다.

- 1536×1024 배경의 기존 수면이 y512이고 원본 좌표를 1:1로 사용한다면, 수면 띠의 위쪽은 **y436**입니다. 계산은 `512 - 76`입니다.
- 이때 띠가 차지하는 세로 구간은 **y436 이상 y564 미만**입니다.
- 화면에서 배경을 확대·축소했다면, 수면 띠에도 **같은 배율과 같은 화면 원점 이동량**을 적용합니다. 휴대폰 화면의 절대 y436에 고정한다는 뜻이 아닙니다.
- 원본 너비보다 화면이 넓으면 같은 장면을 옆으로 반복합니다. 각 시간대와 각 장면에서 가로 배치 기준을 유지합니다.

이는 현재 주문서에 적힌 수면 y512를 기준으로 한 연결 안내입니다. 실제 build-82 화면에서 배경의 위치·배율이 어떻게 적용되는지 확인한 결과는 아닙니다.

## 마젠타 제거와 시간대 전환

원본 PNG는 RGB 그림으로, 알파 채널이 없습니다. 물결 위 하늘 자리의 **`#FF00FF`를 먼저 투명하게 처리**한 뒤 사용합니다. 물결 아래는 불투명하게 남겨 배경의 기존 수면을 덮습니다. 그림의 테두리를 흐리게 만들지 않도록 최근접 보간을 사용합니다.

낮에서 저녁, 저녁에서 밤으로 바꿀 때는 두 시간대의 **같은 장면 번호를 같은 위치와 같은 배율**로 겹쳐 색을 섞습니다. 시간대가 바뀌어도 물결 장면 번호나 가로 이동 위치를 0으로 초기화하지 않습니다. 그래야 물결이 멈추거나 옆으로 뛰지 않습니다.

색을 섞기 전에 마젠타를 투명 처리하세요. 투명 처리한 비트맵끼리 합성하면 물결 위 하늘 자리는 기존 배경을 그대로 보여 줍니다.

낮 띠의 맨 아래는 주문한 **`#0174C5`**입니다. 저녁·밤 띠의 맨 아래는 표에 적힌 색입니다. 현재 프로젝트의 시간대별 배경 바다색도 이 연결 위치에서 맞는지 확인하세요. 최신 배경의 색 전환 방식과 수면 띠의 색을 따로 바꾸면 아래 경계가 드러날 수 있습니다.

## 재생과 미리보기

초기 제안은 **장면당 200ms, 한 바퀴 800ms**입니다. 실제 게임에 적용하거나 속도를 검증한 값은 아니므로, 현재 항해 연출 속도에 맞춰 조정할 수 있습니다. 장면 순서와 시간대별 동기화는 유지합니다.

- `preview/sea_surface_loop.gif`: 원본의 4장면을 순서대로 재생하는 미리보기입니다.
- `preview/sea_surface_comparison.png`: 낮·저녁·밤 색을 비교하는 미리보기입니다.

미리보기는 확인용입니다. 게임에는 `art/`의 원본 PNG를 사용하세요. 정확한 프레임 영역, 색상표, 배치 기준과 파일 해시는 `asset_layout.json`에 있습니다.

## 참고 자료와 확인 범위

이전에 업로드된 프로젝트의 `bg_sea.png`를 회수해 바다색과 픽셀 화풍을 참고했습니다. 회수한 배경은 11월 7일 업로드된 이전 프로젝트 자료로, 현재 build-82와 같은 파일이라고 확인하지 않았습니다. 해당 구버전 그림에는 작은 물결이 이미 그려져 있어, 주문서에 적힌 최신 직선 수면의 대체 적용 화면으로 간주하지 않습니다.

`screenshots/build-82/wave_surface.png`는 확보하지 못했습니다. 따라서 최신 배경 위에 합성한 결과, 실제 게임의 시간대 전환, 기기별 표시와 앱 빌드·설치는 검증하지 않았습니다. 적용 후 수면의 가로 이음새, 기존 직선 경계가 가려지는지, 띠 아래의 바다색 연결, 4→1 반복과 시간대 전환을 실제 화면에서 확인하세요.

이 작업은 수면 그림 연결만을 위한 자료입니다. 현재 게임의 저장 데이터와 선원 성장·강화·보상 수치를 변경할 필요가 없습니다.
