# 리틀 아일랜드 8차 자료

build-31 이후 적용할 짧은 설명, 선원 Lv11~15 성장 자료와 그림입니다. 게임 코드는 수정하지 않았습니다. Claude에서 아래 연결을 구현한 뒤 실제 앱에서 확인하세요.

## 짧은 설명 적용

29는 부품 4, 선원 역할 12, 스킬 60, 장식 32, 부적 24, 기념품 33, 우두머리 8, 특별 항해 24, 건물 6개 설명입니다. 스킬은 기존 36개와 이번 신규 24개를 모두 포함합니다.

모든 값은 공백을 포함해 16자 이하인 한 줄이며 숫자·백분율·줄바꿈을 넣지 않았습니다. 같은 효과는 같은 문구를 사용합니다. 짧은 설명 옆의 수치와 달성 조건은 앱이 실제 데이터로 계산해 표시하세요. 이야기는 그대로 유지합니다.

원본 항목의 ID로 해당 분류를 조회하세요. 예: `29.skills[skill.id]`, `29.charms[charm.id]`. 신규 스킬의 `30.skills[].short`와 `29.skills[id]`는 같습니다. 실제 효과·획득 조건·첫승 여부를 이 설명 문자열에서 파싱하지 마세요.

건물은 주문서에서 지정한 UI 키 6개입니다. 기존 04의 `house_1`·`house_2`·`house_3`는 `house`, `warehouse`는 `store` 설명을 공유합니다. `dock`·`field`·`lighthouse`·`market`은 같은 키입니다. 기존 건물 ID를 바꾸지 마세요. 주문서에 없는 모닥불 설명은 기존 것을 유지합니다.

개발 연결을 위한 30의 규칙 문단을 앱 설명창에 그대로 넣지 마세요. 사용자가 읽는 설명은 29와 `short`를 사용합니다.

## 선원 성장 연결

`xp_to_next_11_15`는 아래 **다음 한 레벨의 비용**입니다. 누적 임계값이나 Lv11→12부터 시작하는 배열이 아닙니다.

| 현재 → 다음 | 필요 경험치 | 정규 귀항만 계산한 횟수 |
|---|---:|---:|
| Lv10 → Lv11 | 800 | 80회 |
| Lv11 → Lv12 | 850 | 85회 |
| Lv12 → Lv13 | 900 | 90회 |
| Lv13 → Lv14 | 950 | 95회 |
| Lv14 → Lv15 | 1,000 | 100회 |

- Lv1~9는 기존 `20.xp_to_next[current_level - 1]`을 유지합니다. Lv9→10은 660입니다.
- 현재 Lv10~14일 때만 `30.xp_to_next_11_15[current_level - 10]`을 읽습니다. Lv15에서는 배열을 조회하지 않고 남은 경험치를 0으로 처리합니다.
- 정규 귀항 경험치 10, 출항 명단 기준 지급, 대기 선원 경험치 없음, 오프라인 최대 8시간 규칙은 유지합니다.
- 20의 정규 경험치와 **23의 임무 첫 성공 경험치 모두** 새 Lv15 공통 레벨 처리로 연결합니다. 23의 옛 Lv10 초과 버림 규칙도 대체해야 합니다. 임무 경험치 자체와 중복 방지 장부는 유지합니다.
- 한 정산에 여러 레벨을 넘으면 비용을 순서대로 차감합니다. 이미 끝난 항해의 효과나 보상을 새 스킬로 다시 계산하지 않습니다.
- 이전 Lv10 상한에서 이미 버린 경험치는 소급 지급하지 않습니다. 기존 레벨·경험치·배치·부적·진행 중 출항 기록을 유지하고, 같은 ID를 다시 병합해도 초기화하지 않습니다.

하루 정도의 성장은 계산 기준입니다. 5단계 배, 돛 Lv20, 선원 시간 감소 합계 0.05, 종이물 항로에서 왕복 671초를 가정했습니다. 하루 두 번 12시간 간격으로 확인해 총 16시간이 인정되고, 같은 선원이 자원 대기 없이 계속 승선하면 한 레벨에 평균 환산 약 0.93~1.16일입니다. Lv10→15는 약 5.24일입니다. 매일 한 레벨을 보장하지 않으며 항로·선원 교대·접속 간격·출항 대기에 따라 달라집니다. 일회성 임무 경험치는 이 계산에서 제외했습니다.

## 신규 스킬과 기존 효과 상한

신규 스킬은 선원마다 Lv12·Lv15에 하나씩 자동 해금합니다. `crew`를 기존 `worker_id`와 연결하고 `id`로 추가 병합합니다. 기존 스킬을 덮어쓰지 않습니다. 별도 금화·재료·스킬 포인트·배 단계 조건은 없습니다.

기존·신규 해금 스킬 + 활성 짝 효과 + 역할 배율을 적용한 부적을 효과별로 합산한 뒤 **기존 effect_caps를 한 번** 적용합니다. 새 스킬용 상한을 따로 만들지 않습니다. 이미 상한인 효과는 실제 증가량이 없을 수 있으므로 표시 수치는 현재 편성 기준으로 계산합니다. 선원 치료나 선체 체력은 추가하지 않습니다.

새 스킬 그림은 기존 `art/skill_icons.png`의 0~15번 칸을 재사용합니다. 이번 ZIP에 기존 시트를 중복 포함하지 않았습니다.

## 그림 적용

세 PNG의 한 칸은 모두 256×256입니다. 마젠타 `#FF00FF`를 투명 처리한 다음 최근접 보간으로 표시하세요. 셀 좌표는 `ART8_MANIFEST.json`에 있습니다.

- 초상은 **Lv11부터** 바뀝니다. 선원 순서는 여울·문기·소리·누리 / 바다·건우·도리·하늘 / 빛여·들·새이·온유입니다. 기존 머리와 모자 특징을 유지하고 남색 코트·금빛 단추·작은 견장으로 바꿨습니다. 갑판 애니메이션은 기존 것을 유지합니다.
- 확인 가능한 원본 `worker_portraits.png`에는 원형 배경이 없고 마젠타만 있습니다. 현재 앱의 원형 색을 임의로 추정해 그림에 넣지 않았습니다. **기존 앱의 동그라미 배경과 그 색을 그대로 두고, 키를 제거한 새 초상만 위에 표시**하세요. build-31의 원형 색 자체는 이 자료로 확인하지 못했습니다.
- 훈련 상자는 인덱스 0=wood, 1=stone, 2=grain, 3=빈 갑판 표시입니다. 기존 28의 퍼즐은 빈칸 없이 두 상자를 교환하므로, 네 번째 그림을 새 자원이나 빈칸 이동 규칙으로 추가하지 마세요. 비어 있는 UI 표시가 필요할 때만 사용합니다.
- 반짝임은 작은 빛 → 큰 별 → 퍼지는 반짝임 → 작은 점의 순서입니다. 같은 크기로 확대하지 말고 256×256 셀을 그대로 이어 표시하세요. 성공한 강화에만 한 번 재생하고, 연출이 끝나거나 생략되어도 저장·재화 정산을 다시 하지 않습니다. 재생 시간은 기존 앱 연출에 맞추세요.
